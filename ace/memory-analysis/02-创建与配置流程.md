## 2. 参数校验细节

### 2.1 名称校验

```go
// internal/service/memory.go: CreateMemory
if strings.TrimSpace(req.Name) == "" {
    return nil, common.NewCodedError(common.ArgumentError, "name is required")
}
```

### 2.2 记忆类型校验

校验 `memory_type` 必须是支持的位标志组合：

```go
// internal/service/memory.go: CreateMemory
const (
    MemoryTypeRaw        = 0b0001  // 原始消息
    MemoryTypeSemantic   = 0b0010  // 语义记忆
    MemoryTypeEpisodic   = 0b0100  // 情景记忆
    MemoryTypeProcedural = 0b1000  // 程序记忆
    AllMemoryTypes       = 0b1111
)

if req.MemoryType <= 0 || req.MemoryType > AllMemoryTypes {
    return nil, common.NewCodedError(common.ArgumentError, 
        "invalid memory_type: must be between 1 and 15")
}
```

用户可以组合多种类型，例如 `0b0011` 表示同时启用原始消息和语义记忆。

### 2.3 权限级别校验

校验 `permissions` 字段只允许三种预定义值：

```go
// internal/service/memory.go: CreateMemory
validPermissions := map[string]bool{
    "me":   true,  // 仅创建者
    "team": true,  // 租户所有成员
    "all":  true,  // 公开（保留，暂未实现）
}

if req.Permissions != "" && !validPermissions[req.Permissions] {
    return nil, common.NewCodedError(common.ArgumentError,
        "permissions must be one of: me, team, all")
}
```

默认值为 `"me"`。

## 3. 租户模型解析

根据用户提供的模型 ID 和租户级别配置，解析出最终使用的嵌入模型和 LLM 模型。

### 3.1 嵌入模型解析

优先级：`embd_id` (用户指定) > `tenant_embd_id` (租户默认) > 系统默认

```go
// internal/service/memory.go: CreateMemory
embdID := req.EmbdID
if embdID == "" {
    // 获取租户默认嵌入模型
    tenant, err := s.tenantDAO.GetByID(ctx, userID) // 用户即租户
    if err != nil {
        return nil, err
    }
    embdID = tenant.EmbdID  // 租户级别配置
}

// 验证模型存在性
if embdID != "" {
    _, err := s.llmDAO.GetByID(ctx, embdID)
    if err != nil {
        return nil, common.NewCodedError(common.ArgumentError,
            "embedding model not found")
    }
}
```

### 3.2 LLM 模型解析

LLM 模型用于后续的异步记忆提取，解析逻辑与嵌入模型相同：

| 字段 | 含义 | 用途 |
|------|------|------|
| tenant_llm_id | 租户级 LLM 配置 | 回退默认值 |
| llm_id | Memory 实际使用的 LLM | 提取语义/情景/程序记忆 |
| tenant_embd_id | 租户级嵌入模型配置 | 回退默认值 |
| embd_id | Memory 实际使用的嵌入模型 | 向量化消息内容 |

关键设计：**四个字段都持久化到 Memory 表**。原因是租户配置可能后续变更，而已建立的记忆索引必须继续使用创建时的嵌入模型，否则向量维度不匹配会导致检索失败。

## 4. 名称去重检查

同一租户下 Memory 名称必须唯一：

```go
// internal/service/memory.go: CreateMemory
existing, err := s.memoryDAO.GetByTenantAndName(ctx, tenantID, req.Name)
if err != nil && !errors.Is(err, gorm.ErrRecordNotFound) {
    return nil, err
}
if existing != nil {
    return nil, common.NewCodedError(common.DuplicateName,
        fmt.Sprintf("memory with name %q already exists", req.Name))
}
```

注意去重范围是 `(tenant_id, name)` 组合，不同租户可以使用相同名称。

## 5. 默认值填充

未指定的字段填充系统默认值：

```go
// internal/service/memory.go: CreateMemory
memory := &entity.Memory{
    ID:               common.GenerateUUID(),
    TenantID:         tenantID,
    CreatedBy:        userID,
    Name:             req.Name,
    Description:      req.Description,
    MemoryType:       req.MemoryType,
    StorageType:      "table",      // 存储类型，当前仅支持 table
    Permissions:      "me",         // 默认仅创建者可见
    MemorySize:       5242880,      // 5MB 配额上限
    ForgettingPolicy: "FIFO",       // 超配额时先淘汰最旧记忆
    Temperature:      0.5,          // LLM 提取温度
    TenantEmbdID:     tenantEmbdID,
    EmbdID:           embdID,
    TenantLLMID:      tenantLLMID,
    LLMID:            llmID,
}
```

各默认值的设计意图：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| storage_type | "table" | 预留字段，未来可能支持图存储 |
| permissions | "me" | 最小权限原则 |
| memory_size | 5242880 (5MB) | 单个 Memory 的内容总字节配额 |
| forgetting_policy | "FIFO" | 超配额时按创建时间淘汰 |
| temperature | 0.5 | 平衡提取的稳定性与多样性 |

## 6. 系统提示词组装

系统提示词 (system_prompt) 用于指导 LLM 如何从原始对话中提取结构化记忆。

### 6.1 提示词模板结构

```python
# memory/utils/prompt_util.py: PromptAssembler
TYPE_INSTRUCTIONS = {
    "semantic": "Extract general facts, knowledge...",
    "episodic": "Extract specific events with temporal context...",
    "procedural": "Extract step-by-step procedures..."
}

OUTPUT_TEMPLATES = {
    "semantic": {
        "content": "The extracted fact",
        "valid_at": "ISO 8601 timestamp when this became valid",
        "invalid_at": "ISO 8601 timestamp when this became invalid (optional)"
    },
    # episodic 和 procedural 类似结构
}
```

### 6.2 组装逻辑

根据 `memory_type` 位标志组合多类型的指令：

```python
# memory/utils/prompt_util.py: assemble_system_prompt
def assemble_system_prompt(memory_type: int, temperature: float) -> str:
    instructions = []
    
    if memory_type & MemoryTypeRaw:
        instructions.append(TYPE_INSTRUCTIONS["raw"])
    if memory_type & MemoryTypeSemantic:
        instructions.append(TYPE_INSTRUCTIONS["semantic"])
    if memory_type & MemoryTypeEpisodic:
        instructions.append(TYPE_INSTRUCTIONS["episodic"])
    if memory_type & MemoryTypeProcedural:
        instructions.append(TYPE_INSTRUCTIONS["procedural"])
    
    return SYSTEM_PROMPT_TEMPLATE.format(
        instructions="\n".join(instructions),
        output_format=json.dumps(OUTPUT_TEMPLATES),
        temperature=temperature
    )
```

关键要求：

- **JSON 输出格式**：LLM 必须返回结构化 JSON，包含 `content`、`valid_at`、`invalid_at` 字段
- **ISO 8601 时间戳**：所有时间字段使用标准格式 `YYYY-MM-DDTHH:MM:SSZ`
- **温度参数**：控制提取的随机性，0.5 是平衡点

### 6.3 默认提示词检测

系统维护一个默认提示词标识 `is_default_system_prompt`，用于判断用户是否自定义了提示词：

```python
# api/db/services/memory_service.py
is_default = (system_prompt == assemble_system_prompt(memory_type, temperature))
```

这个标识影响后续的 UpdateMemory 行为（见 7.2 节）。

## 7. 更新流程 (UpdateMemory)

### 7.1 差异化更新

只更新用户实际传入的字段，避免覆盖未修改的配置：

```go
// internal/service/memory.go: UpdateMemory
filteredUpdateDict := make(map[string]interface{})

if req.Name != nil {
    filteredUpdateDict["name"] = *req.Name
}
if req.Description != nil {
    filteredUpdateDict["description"] = *req.Description
}
if req.Permissions != nil {
    filteredUpdateDict["permissions"] = *req.Permissions
}
// ... 其他可选字段

if len(filteredUpdateDict) == 0 {
    return nil, nil  // 无变更，直接返回
}
```

请求体中的字段使用指针类型，用 `nil` 区分"未传入"和"传入空值"。

### 7.2 不可变字段保护

当 Memory 已经存在消息时，某些字段禁止修改：

```go
// internal/service/memory.go: UpdateMemory
hasMessages, err := s.memoryDAO.HasMessages(ctx, memoryID)
if err != nil {
    return nil, err
}

if hasMessages {
    // 嵌入模型变更会导致向量维度不匹配
    if req.TenantEmbdID != nil || req.EmbdID != nil {
        return nil, common.NewCodedError(common.ArgumentError,
            "cannot change embedding model: memory already has messages")
    }
    // 记忆类型变更会导致已提取记忆的语义不一致
    if req.MemoryType != nil {
        return nil, common.NewCodedError(common.ArgumentError,
            "cannot change memory_type: memory already has messages")
    }
}
```

保护原因：

| 字段 | 保护原因 |
|------|----------|
| tenant_embd_id / embd_id | 不同模型输出的向量维度不同，已建立索引无法混用 |
| memory_type | 已提取的记忆按旧类型组织，类型变更会造成语义断层 |

### 7.3 提示词自动重新生成

如果用户从未自定义提示词（`is_default_system_prompt == true`），而 `memory_type` 或 `temperature` 发生变更，系统会自动重新组装提示词：

```go
// internal/service/memory.go: UpdateMemory
if memory.IsDefaultSystemPrompt {
    if req.MemoryType != nil || req.Temperature != nil {
        newPrompt := assembleSystemPrompt(newMemoryType, newTemperature)
        filteredUpdateDict["system_prompt"] = newPrompt
    }
}
```

如果用户已自定义提示词，系统不会覆盖，交由用户自行维护。

## 8. 删除流程 (DeleteMemory)

删除 Memory 是级联操作，需要清理多个存储层：

```
  DeleteMemory(memoryID)
         │
         ▼
  1. 权限检查：requireMemoryAccess
         │
         ▼
  2. 删除文档引擎中的所有文档
     doc_store.delete({"memory_id": memoryID}, index_name)
         │
         ▼
  3. 删除关联的 MemoryTask 记录
     memory_task_dao.DeleteByMemoryID(memoryID)
         │
         ▼
  4. 删除 Memory 主记录
     memory_dao.Delete(memoryID)
         │
         ▼
  5. 清理 Redis 缓存
     redis.Del("memory_" + memoryID)
```

注意顺序：先清理外部存储（文档引擎），最后删除主记录。如果中间失败，主记录仍然存在，可以重试删除。反之如果先删主记录，孤立的索引文档将无法定位清理。

## 9. 权限检查

所有 Memory 操作都经过统一的权限检查：

```go
// internal/service/memory.go: requireMemoryAccess
func (s *MemoryService) requireMemoryAccess(
    ctx context.Context, memoryID, userID string,
) (*entity.Memory, error) {
    memory, err := s.memoryDAO.GetByID(ctx, memoryID)
    if err != nil {
        return nil, err
    }
    
    // 创建者始终有权限
    if memory.CreatedBy == userID {
        return memory, nil
    }
    
    // team 权限：检查用户是否属于同一租户
    if memory.Permissions == "team" {
        isMember, err := s.userTenantDAO.IsMember(ctx, memory.TenantID, userID)
        if err != nil {
            return nil, err
        }
        if isMember {
            return memory, nil
        }
    }
    
    return nil, common.NewCodedError(common.AuthError, "no access to this memory")
}
```

列表查询使用 `filterAccessibleMemories` 做批量过滤，逻辑等价但避免 N+1 查询。
