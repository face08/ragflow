# RAGFlow Memory 模块 — 异步提取流程

## 1. 提取流程总览

异步提取是分布式任务处理流程，多个工作者竞争领取任务：

```
  ┌─────────────────────┐
  │  NATS 唤醒消息       │
  │  或定期扫描          │
  └──────────┬──────────┘
             ▼
  ┌─────────────────────────────┐
  │ 1. 领取任务 (Claim)          │
  │    SELECT FOR UPDATE         │
  └──────────┬──────────────────┘
             ▼
  ┌─────────────────────────────┐
  │ 2. 读取原始消息              │
  │    docStore.Get(raw_id)     │
  └──────────┬──────────────────┘
             ▼
  ┌─────────────────────────────┐
  │ 3. LLM 提取                  │
  │    extractByLLM (进度 0.5)   │
  └──────────┬──────────────────┘
             ▼
  ┌─────────────────────────────┐
  │ 4. 解析与验证 JSON           │
  │    parseMemoryExtraction     │
  └──────────┬──────────────────┘
             ▼
  ┌─────────────────────────────┐
  │ 5. 向量化提取记忆            │
  │    embedAndSave (进度 1.0)   │
  └──────────┬──────────────────┘
             ▼
  ┌─────────────────────────────┐
  │ 6. 标记完成                  │
  │    CompleteTask              │
  └─────────────────────────────┘
```

关键特性：
- **租约机制**：防止多个工作者重复处理同一任务
- **进度持久化**：每步完成后更新数据库，支持中断恢复
- **指数退避重试**：5 秒 → 5 分钟，最多 10 次
- **永久失败识别**：LLM 返回格式错误、模型不存在等不可恢复错误

## 2. 任务领取与租约

### 2.1 竞争性领取

多个工作者同时尝试领取，只有一个成功：

```go
// internal/dao/memory_task.go: Claim
func (d *MemoryTaskDAO) Claim(ctx context.Context, workerID string) (*entity.MemoryTask, error) {
    now := time.Now()
    leaseTTL := 2 * time.Minute
    
    // SELECT FOR UPDATE 确保原子性
    tx := d.db.Begin()
    defer tx.Rollback()
    
    var task entity.MemoryTask
    err := tx.Where("state = ? AND next_run_at <= ?", "pending", now).
        Where("(lease_owner = ? OR lease_expire_at < ?)", "", now).
        Order("next_run_at ASC").
        First(&task).Error
    
    if err != nil {
        return nil, err
    }
    
    // 设置租约
    task.LeaseOwner = workerID
    task.LeaseExpireAt = now.Add(leaseTTL).UnixMilli()
    task.State = "extracting"
    
    if err := tx.Save(&task).Error; err != nil {
        return nil, err
    }
    
    tx.Commit()
    return &task, nil
}
```

条件解读：
- `state = 'pending'`：只领取等待中的任务
- `next_run_at <= now`：到达可执行时间
- `lease_owner = '' OR lease_expire_at < now`：无持有者或租约已过期

### 2.2 租约续期

长时间运行的 LLM 调用需要定期续期，防止租约过期被其他工作者抢占：

```go
// internal/dao/memory_task.go: RenewLease
func (d *MemoryTaskDAO) RenewLease(ctx context.Context, taskID, workerID string) error {
    now := time.Now()
    newExpireAt := now.Add(2 * time.Minute).UnixMilli()
    
    result := d.db.Model(&entity.MemoryTask{}).
        Where("id = ? AND lease_owner = ?", taskID, workerID).
        Update("lease_expire_at", newExpireAt)
    
    if result.RowsAffected == 0 {
        return ErrLeaseNotOwned
    }
    return nil
}
```

续期策略：每 30 秒续期一次，租约 TTL 为 2 分钟。

### 2.3 租约过期恢复

如果工作者意外崩溃，租约过期后任务会被其他工作者重新领取：

```
  时间轴：
  T0: Worker A 领取任务，lease_expire_at = T0 + 2min
  T0+30s: Worker A 续期，lease_expire_at = T0 + 2.5min
  T0+1min: Worker A 崩溃，停止续期
  T0+2.5min: 租约过期
  T0+3min: Worker B 扫描到租约过期的任务，重新领取
```

## 3. LLM 提取

### 3.1 提取请求构造

```go
// internal/service/memory_extractor.go: extractByLLM
func (s *MemoryExtractorService) extractByLLM(
    ctx context.Context, memory *entity.Memory, rawMessage string,
) (string, error) {
    llmModel, err := s.llmDAO.GetByID(ctx, memory.LLMID)
    if err != nil {
        return "", err
    }
    
    req := &LLMRequest{
        Model:       llmModel.Name,
        Messages: []Message{
            {Role: "system", Content: memory.SystemPrompt},
            {Role: "user", Content: rawMessage},
        },
        Temperature: memory.Temperature,
        MaxTokens:   2048,
    }
    
    resp, err := s.llmClient.Complete(ctx, req)
    if err != nil {
        return "", fmt.Errorf("llm call failed: %w", err)
    }
    
    return resp.Content, nil
}
```

### 3.2 进度更新

LLM 调用完成后立即更新进度到 0.5（提取阶段完成，等待向量化）：

```go
// internal/dao/memory_task.go: PersistExtraction
func (d *MemoryTaskDAO) PersistExtraction(
    ctx context.Context, taskID, extractedJSON string,
) error {
    return d.db.Model(&entity.MemoryTask{}).
        Where("id = ?", taskID).
        Updates(map[string]interface{}{
            "extracted_json": extractedJSON,
            "progress":       0.5,
            "update_time":    time.Now().UnixMilli(),
        }).Error
}
```

这样即使后续向量化失败，下次恢复时可以跳过 LLM 调用，直接从 `extracted_json` 字段读取。

## 4. JSON 解析与验证

### 4.1 预期格式

LLM 必须返回符合以下结构的 JSON：

```json
[
  {
    "content": "User prefers dark mode",
    "valid_at": "2026-09-18T10:30:00Z",
    "invalid_at": null
  },
  {
    "content": "Meeting scheduled at 3 PM",
    "valid_at": "2026-09-18T15:00:00Z",
    "invalid_at": "2026-09-18T16:00:00Z"
  }
]
```

### 4.2 容错解析

LLM 输出常带有 Markdown 代码块包裹，需要预处理：

```go
// internal/service/memory_extractor.go: parseMemoryExtraction
func parseMemoryExtraction(raw string) ([]ExtractedMemory, error) {
    // 剥离 markdown 代码块标记
    cleaned := strings.TrimSpace(raw)
    cleaned = strings.TrimPrefix(cleaned, "```json")
    cleaned = strings.TrimPrefix(cleaned, "```")
    cleaned = strings.TrimSuffix(cleaned, "```")
    cleaned = strings.TrimSpace(cleaned)
    
    var items []ExtractedMemory
    if err := json.Unmarshal([]byte(cleaned), &items); err != nil {
        // 格式错误属于永久失败，不重试
        return nil, &PermanentError{
            Reason: fmt.Sprintf("invalid json from llm: %v", err),
        }
    }
    
    return items, nil
}
```

### 4.3 字段校验

```go
for i, item := range items {
    if strings.TrimSpace(item.Content) == "" {
        return nil, &PermanentError{
            Reason: fmt.Sprintf("item %d has empty content", i),
        }
    }
    
    // valid_at 必须是合法 ISO 8601
    if item.ValidAt != "" {
        if _, err := time.Parse(time.RFC3339, item.ValidAt); err != nil {
            // 时间格式错误时降级为当前时间，不中断流程
            item.ValidAt = time.Now().Format(time.RFC3339)
        }
    }
}
```

设计取舍：`content` 为空是致命错误（提取无意义），时间格式错误可以降级处理。

## 5. 提取记忆入库

### 5.1 构建提取记忆文档

```go
// internal/service/memory_extractor.go: buildExtractedMessage
func buildExtractedMessage(
    memoryID, rawID string, messageID int64,
    item ExtractedMemory, memoryType int,
) map[string]interface{} {
    return map[string]interface{}{
        "id":          fmt.Sprintf("%s_%d", memoryID, messageID),
        "memory_id":   memoryID,
        "memory_type": memoryType,      // semantic / episodic / procedural
        "content":     item.Content,
        "source_id":   rawID,           // 指向原始消息
        "valid_at":    item.ValidAt,
        "invalid_at":  item.InvalidAt,
        "create_time": time.Now().UnixMilli(),
        "forget_at":   0,
    }
}
```

关键字段 `source_id`：建立提取记忆到原始消息的追溯链，用于消息列表展示时把提取结果挂到原始消息下（详见 05-检索流程）。

### 5.2 批量向量化写入

每条提取记忆都需要独立向量化：

```go
for _, item := range items {
    embedding, err := s.embeddingClient.Embed(ctx, item.Content)
    if err != nil {
        return err  // 可重试错误
    }
    
    doc := buildExtractedMessage(...)
    doc[vectorField] = embedding
    docs = append(docs, doc)
}

err = docStore.Insert(ctx, indexName, docs)
```

## 6. 任务完成与清理

### 6.1 标记完成

```go
// internal/dao/memory_task.go: Complete
err := d.db.Model(&entity.MemoryTask{}).
    Where("id = ?", taskID).
    Updates(map[string]interface{}{
        "state":            "completed",
        "progress":         1.0,
        "lease_owner":      "",     // 释放租约
        "lease_expire_at":  0,
        "complete_time":    time.Now().UnixMilli(),
    }).Error
```

完成后任务不会被删除，保留用于审计和调试。

### 6.2 失败处理

临时失败（网络超时、LLM 限流）触发重试，永久失败（JSON 格式错误）直接标记为 `failed`：

```go
// internal/dao/memory_task.go: ScheduleRetry
func (d *MemoryTaskDAO) ScheduleRetry(
    ctx context.Context, taskID string, attempts int, reason string,
) error {
    // 指数退避：5s, 10s, 20s, ..., 最大 5min
    delay := time.Duration(math.Min(
        float64(5<<attempts),
        float64(5*60),
    )) * time.Second
    
    nextRunAt := time.Now().Add(delay)
    
    return d.db.Model(&entity.MemoryTask{}).
        Where("id = ?", taskID).
        Updates(map[string]interface{}{
            "state":            "pending",
            "attempts":         attempts + 1,
            "next_run_at":      nextRunAt,
            "error_message":    reason,
            "lease_owner":      "",
            "lease_expire_at":  0,
        }).Error
}
```

### 6.3 永久失败标记

```go
// internal/dao/memory_task.go: MarkFailed
func (d *MemoryTaskDAO) MarkFailed(ctx context.Context, taskID, reason string) error {
    return d.db.Model(&entity.MemoryTask{}).
        Where("id = ?", taskID).
        Updates(map[string]interface{}{
            "state":            "failed",
            "progress":         -1.0,
            "error_message":    reason,
            "lease_owner":      "",
            "lease_expire_at":  0,
            "complete_time":    time.Now().UnixMilli(),
        }).Error
}
```

永久失败场景：
- LLM 返回非 JSON 格式
- 提取内容全部为空
- Memory 配置的模型不存在
- 达到最大重试次数（10 次）

## 7. 错误分类与重试策略

| 错误类型 | 示例 | 重试 | 退避 |
|----------|------|------|------|
| 临时网络错误 | connection timeout | ✓ | 5s → 5min |
| LLM 限流 | rate limit exceeded | ✓ | 5s → 5min |
| LLM 服务不可用 | 503 Service Unavailable | ✓ | 5s → 5min |
| JSON 格式错误 | unexpected token | ✗ | 永久失败 |
| 模型不存在 | model not found | ✗ | 永久失败 |
| 内容为空 | all extractions empty | ✗ | 永久失败 |
| 超过最大重试 | attempts >= 10 | ✗ | 永久失败 |

## 8. 调度器与兜底机制

### 8.1 定期扫描

ReconcileMemoryTasks 每 30 秒扫描一次，确保任务不会因 NATS 消息丢失而永久挂起：

```go
// internal/service/memory_extractor.go: ReconcileMemoryTasks
func (s *MemoryExtractorService) ReconcileMemoryTasks(ctx context.Context) {
    ticker := time.NewTicker(30 * time.Second)
    defer ticker.Stop()
    
    for {
        select {
        case <-ticker.C:
            tasks, err := s.memoryTaskDAO.ListDue(ctx, 100)
            if err != nil {
                log.Error("list due tasks failed", "error", err)
                continue
            }
            
            for _, task := range tasks {
                go s.HandleSaveToMemoryTask(ctx, task.ID)
            }
            
        case <-ctx.Done():
            return
        }
    }
}
```

### 8.2 ListDue 条件

```go
// internal/dao/memory_task.go: ListDue
func (d *MemoryTaskDAO) ListDue(ctx context.Context, limit int) ([]*entity.MemoryTask, error) {
    var tasks []*entity.MemoryTask
    now := time.Now()
    
    err := d.db.Where("state = ? AND next_run_at <= ?", "pending", now).
        Where("lease_owner = ? OR lease_expire_at < ?", "", now).
        Order("next_run_at ASC").
        Limit(limit).
        Find(&tasks).Error
    
    return tasks, err
}
```

## 9. 中断恢复

系统重启或工作者切换时，任务可以从中间状态恢复：

| 任务状态 | progress | 恢复行为 |
|----------|----------|----------|
| pending | 0 | 完整执行全流程 |
| extracting | 0.5（已有 extracted_json） | 跳过 LLM 调用，直接向量化 |
| extracting | 0.15（LLM 调用中） | 租约过期后重新 LLM 调用 |
| stored | 0.9 | 标记完成即可（罕见） |
| completed | 1.0 | 不处理 |
| failed | -1.0 | 不处理 |

关键设计：`extracted_json` 持久化后，即使后续失败，重试时无需再次调用 LLM（节省成本和时间）。
